# 11. UI

Menus, HUDs, buttons, text input — Bevy's own retained-mode UI system (flexbox/grid-based layout), separate from anything drawn in world space. The biggest single category after 3D rendering.

## Representative examples — Layout & styling

- `ui/layout/flex_layout.rs` — flexbox-style `AlignItems`/`JustifyContent`
- `ui/layout/grid.rs` — CSS Grid layout
- `ui/styling/borders.rs`, `ui/styling/box_shadow.rs`, `ui/styling/gradients.rs` — visual styling
- `ui/scroll_and_overflow/scroll.rs`, `overflow.rs` — scrolling containers and clipping

## Representative examples — Widgets & text

- `ui/widgets/button.rs` — the canonical interactive widget
- `ui/widgets/standard_widgets.rs` — headless/core widget set
- `ui/widgets/feathers_gallery.rs` — "Feathers," Bevy's higher-level styled widget kit
- `ui/text/text.rs` — create/update text
- `ui/text/text_input.rs`, `ui/text/multiline_text_input.rs` — editable text fields
- `ui/navigation/directional_navigation.rs` — arrow-key/gamepad navigation between UI elements

## Representative examples — Integration with the world

- `ui/render_ui_to_texture.rs` — UI as a texture inside a 3D scene
- `camera/2d_on_ui.rs` — 2D world objects layered on top of UI
- `ui/ui_target_camera.rs` — route UI to a specific camera
